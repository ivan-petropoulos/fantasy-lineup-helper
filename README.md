# fantasy-lineup-helper


A personal tool that aggregates Reddit discussion (injury reports, 
player news, community sentiment) from fantasy-sports subreddits 
to help inform lineup and add/drop decisions.

Status: In development — pending Reddit API access approval.

## Planned functionality
- Read-only queries to Reddit Data API (OAuth)
- Parses posts/comments from a fixed set of subreddits for 
  player names, injury keywords, sentiment
- Generates personal lineup recommendations

No write actions (posting/commenting/voting) are performed.
